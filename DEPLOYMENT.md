# OrianaaClub deployment guides

- For the Node.js API server, see [Backend/DEPLOY.md](./Backend/DEPLOY.md).
- For static frontend deployment to Hostinger, see [frontend/DEPLOYMENT.md](./frontend/DEPLOYMENT.md).

The frontend is a Vite static build; the API must be deployed independently on a Node.js server. Do not upload backend secrets to the static hosting account.
